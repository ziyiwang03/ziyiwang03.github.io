# Ziyi Wang — Academic Homepage

Personal academic website for Ziyi Wang, published with GitHub Pages.

The site is a dependency-free static website with:

- light and dark themes;
- MathJax support for LaTeX;
- pages for publications, research, teaching, studies, blogs, and life;
- course and summer-school pages;
- responsive layouts for desktop and mobile.

## Local preview

Serve this directory with any static web server, then open `index.html` through
the local server.
